# Радар возможностей

Сайт + парсер: раз в день собирает стажировки, школы, кейсы и саммиты в `docs/events.json`, сайт (`docs/index.html`) показывает их с фильтрами.

## Запуск на GitHub (один раз)
1. Создай на GitHub новый репозиторий (например `radar`), загрузи в него все файлы этой папки (включая скрытую папку `.github`).
2. **Settings → Pages**: Source = *Deploy from a branch*, ветка `main`, папка `/docs`. Через пару минут сайт будет по адресу `https://<твой-ник>.github.io/radar/`.
3. **Settings → Actions → General → Workflow permissions**: выбери *Read and write permissions*.
4. Вкладка **Actions → daily-parse → Run workflow**: первый запуск вручную. Дальше парсер идёт сам каждый день.

## Локальная проверка
```
pip install -r requirements.txt
python parse.py
python parse.py --inspect https://leader-id.ru   # подсказывает, как настроить селекторы
```
После запуска открой `docs/events.json` и посмотри, что нашлось.

## Как добавлять источники
Открой `sources.yml`, скопируй блок и поменяй поля. Для Telegram-канала достаточно имени канала (из ссылки `t.me/имя`). Свои проверенные карточки вручную добавляй в `data/manual.json`: они не затираются парсером.

## Важно
- Парсер уважает `robots.txt` и делает паузы между запросами.
- Автоматически извлечённые карточки помечены «уточнить»: даты, цена и дедлайн берутся из текста по правилам и могут ошибаться. Проверяй по ссылке на официальный сайт.
- Сайты на JavaScript (часть корпоративных карьерных страниц) без доработки не читаются.

## Без GitHub Pages
После каждого запуска парсер создаёт `docs/radar.html`: это тот же сайт, но с данными внутри. Его можно открыть двойным кликом на компьютере, отправить себе в Telegram или выложить на любой бесплатный хостинг (Netlify Drop, Cloudflare Pages). Pages на бесплатном тарифе GitHub работает только с публичными репозиториями.

## Источники из таблицы
Все ссылки лежат в `data/istochniki.xlsx` (колонка D, несколько ссылок через « ; »). После изменения таблицы запусти `python table_to_sources.py`, он обновит `sources_table.yml`. Сайты на JS и «вручную» в нём выключены (`enabled: false`): для них добавляй карточки в `data/manual.json`.
