# Радар будущего

Личный журнал возможностей: конференции, стипендии и гранты, кейс-чемпионаты, стажировки, летние школы и прочее, в России и в мире. Каждое утро GitHub Actions запускает парсер, ИИ раскладывает найденное по полям, а сайт (`docs/index.html`) показывает выпуск с рейтингом «совпадение с интересами».

## Что есть на сайте
- **Выпуск.** Главная возможность дня, «горящие» дедлайны (до 21 дня), новое за неделю и рубрики.
- **Деловая лента.** Свежие бизнес-новости за последние дни: «В России» (Ведомости, Коммерсантъ, Frank Media, The Bell, Строительная газета) и «В мире» (Bloomberg, BBC, The Guardian, The Economist, TechCrunch, Sifted, Global Construction Review). Фильтр по темам интересов.
- **Рубрики-каталоги.** Поиск и фильтры: интересы, онлайн или очно, деньги, наличие дедлайна, сортировка.
- **Регион.** Переключатель «Все / Россия / Мир» вверху работает во всех разделах.
- **Календарь.** Дедлайны и старты по месяцам.
- **Мой план.** Статусы «Хочу → Готовлю заявку → Подала → Результат». Можно выгрузить все дедлайны плана в календарь (.ics) с напоминанием за 3 дня.
- **Карточка.** Все поля, статус, кнопка «В календарь», кнопка «Не интересно» (скрывает карточку).

Избранное и статусы хранятся в браузере (localStorage), поэтому на телефоне и на компьютере они разные.

## Запуск на GitHub (один раз)
1. Загрузи все файлы этой папки в репозиторий, включая скрытую папку `.github`.
2. **Settings → Pages**: Source = *Deploy from a branch*, ветка `main`, папка `/docs`.
3. **Settings → Actions → General → Workflow permissions**: выбери *Read and write permissions*.
4. **Actions → daily-parse → Run workflow**: первый запуск вручную. Дальше он идёт сам каждый день в 07:00 по Москве.

## ИИ-разбор (очень рекомендую)
Без ИИ поля заполняются регулярными выражениями, и многие остаются пустыми. С ИИ каждая запись получает нормальное русское название, даты, дедлайн, стоимость, условия, теги и оценку «насколько подходит».
1. Возьми бесплатный ключ Google Gemini: https://aistudio.google.com/apikey
2. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret**: имя `LLM_API_KEY`, значение — ключ.
3. По желанию на вкладке **Variables** задай `LLM_MODEL` (по умолчанию `gemini-2.5-flash`). Подойдёт любой сервис с OpenAI-совместимым API: укажи `LLM_BASE_URL` и `LLM_MODEL`.

Разобранные записи кешируются в `data/llm_cache.json`, поэтому каждая отправляется в ИИ только один раз. За запуск разбирается до 120 новых записей.

## Сводка в Telegram (по желанию)
1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Напиши своему боту `/start`, а свой id узнай у [@userinfobot](https://t.me/userinfobot).
3. Добавь секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, а в Variables — `SITE_URL` (адрес сайта).

Каждое утро бот присылает новые возможности с совпадением от 55% и напоминает о дедлайнах за 7, 3 и 1 день.

## Настройка под себя
- `profile.yml` — интересы и слова для тегов, «престижные» организации и слова, которые снижают рейтинг (например «для школьников»).
- `data/manual_curated.json` — проверенная подборка топовых возможностей. Добавляй свои по тому же образцу. Все файлы `data/manual*.json` подхватываются автоматически и не затираются парсером.
- `news.yml` — издания для деловой ленты: добавь любой RSS или Telegram-канал.
- `sources.yml` (там же Telegram-каналы: Стадика, СберСтудент, Бизнес-клуб МГУ, центры карьеры МГУ, МГИМО, Финуниверситета, РЭШ, Changellenge, CASE-IN, гранты и стипендии; агрегатор FutureToday; архитектурные конкурсы) и `data/istochniki.xlsx` → `python table_to_sources.py` → `sources_table.yml` — источники.

Поля карточки: `sec` (conf, grant, case, intern, school, other), `region` (ru, intl), `title`, `org`, `place`, `fmt`, `dates`, `start_iso`, `dl`, `dl_iso` (ГГГГ-ММ-ДД), `cost`, `funded` (1, если расходы покрываются), `cond`, `desc`, `url`, `tags` (fin, build, lead, consult, pm, it), `top` (1 — поднять в рейтинге).

## Локальная проверка
```
pip install -r requirements.txt
python parse.py              # полный обход источников
python parse.py --offline    # только ручные карточки, быстро
python parse.py --inspect https://leader-id.ru
```
После запуска открой `docs/radar.html` двойным кликом: это тот же сайт, но с данными внутри.

## Важно
- Парсер уважает `robots.txt` и делает паузы между запросами.
- Карточки с пометкой «проверено» сверены вручную. Остальные сверяй с официальным сайтом перед подачей.
- Карточки с прошедшим дедлайном исчезают автоматически.
